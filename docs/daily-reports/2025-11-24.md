## 09:28 Android 動作確認とバグ修正

### 概要
Android実機での動作確認を実施し、発見されたバグを修正。最終的に画像アップロードとキャプション生成が正常動作することを確認。

### 発見された問題と修正

#### 1. Android での Base64変換エラー
**問題:**
- Androidでキャプション生成時に「Method readAsStringAsync is deprecated」エラー

**原因:**
- Expo SDK 54 で `expo-file-system` の `readAsStringAsync` が非推奨になった
- 新APIは `expo-file-system/legacy` からインポートする必要がある

**修正内容:**
- `src/services/geminiService.ts`: `import * as FileSystem from 'expo-file-system/legacy';`
- `src/services/githubService.ts`: 同様に修正
- `__tests__/geminiService.test.ts`: テストのモックも更新

**コミット:** `660a454` - fix: expo-file-systemのlegacy APIに移行

#### 2. 画像がBase64テキストとしてコミットされる問題
**問題:**
- GitHubにアップロードされた画像ファイルがBase64テキストとして保存され、Obsidianで表示されない

**原因:**
- GitHub Tree APIで直接 `content` を指定すると、バイナリファイルが正しく処理されない
- バイナリファイルは先にBlob APIでblobを作成し、そのSHAをTree APIで参照する必要がある

**修正内容:**
```typescript
// 修正前: Tree APIに直接contentを指定
treeEntries.push({
  path: imagePath,
  mode: '100644',
  type: 'blob',
  content: base64Image,
  encoding: 'base64',
});

// 修正後: Blob APIでblobを作成してSHAを参照
const { data: blob } = await this.octokit!.git.createBlob({
  owner: this.config.owner,
  repo: this.config.repo,
  content: base64Image,
  encoding: 'base64',
});

treeEntries.push({
  path: imagePath,
  mode: '100644',
  type: 'blob',
  sha: blob.sha,
});
```

**コミット:** `8513892` - fix: 画像ファイルをバイナリとして正しくアップロード

#### 3. URI正規化とデバッグログ追加
